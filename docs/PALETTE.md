# Palette

Every colour in the site, the mockups and the exports is a step of **palette-0** by Elli (https://palette.elligene.com, v2.6.71). The full set is in `src/app/palette-0.css` as `--p0-{hue}-{step}` variables. The two themes keep their names and roles; only the hex values moved onto palette-0.
